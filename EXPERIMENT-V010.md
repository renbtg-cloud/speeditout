# Speedit out v0.10 — Evidence-limited audio adaptation laboratory

## What was built

- Own Go audio assessment package, with limited, explicit evidence and no external API.
- Real HTTP JSON endpoint `POST /v1/audio/assess` in the existing Go service.
- WAV/PCM16 level and clipping inspector CLI (`cmd/audioinspect`).
- Future React Native/Web client transport types (not an app and not native audio capture).
- Adversarial unit/API tests, with Go race detector.
- A/B FFmpeg `afftdn` smoke test on synthesized speech plus seeded noise.

## Synthetic denoising result

Results are generated by `python experiments/audio/experiment.py`, in `experiments/audio/denoise-results.json`.
The test uses espeak Brazilian Portuguese speech, 16 kHz mono, Gaussian white noise at -5, 0 and +5 dB reference SNR; FFmpeg's `afftdn` filter; and scale-invariant SDR aligned within 100 ms.

| Input synthetic SNR | Before SI-SDR | After SI-SDR | Delta |
|---|---:|---:|---:|
| -5 dB | -5.009 dB | -4.831 dB | +0.178 dB |
| 0 dB | +0.003 dB | +0.559 dB | +0.556 dB |
| +5 dB | +4.987 dB | +6.654 dB | +1.667 dB |

**Interpretation:** modest signal metric improvements in this artificial experiment. NOT a result on real human recordings, true voice intelligibility, or ASR word-error rate. The filter added about 25 ms delay in this measurement (400 samples at 16 kHz). Some processing configurations could harm recognition, so enhancement remains OFF by default and is not part of the shipping pipeline.

## Safety and quality

- Never claim the microphone/device is defective based on RMS alone.
- Never invent an unheard transcript or assert user intent from weak speech.
- Preserve the recognized words verbatim for confirmation, including swear words.
- Avoid repeated hardware advice, unless the user is encountering trouble.
- Never auto-send communication on behalf of the user.
- Keep existing v0.9 semantic interpreter and its regression tests intact.

## Evidence still needed

This is a **prototype of graceful communication failure**. It does not solve real-world speech recognition yet. Future controlled user trials must measure intelligibility/ASR accuracy and genuinely helpful guidance.
